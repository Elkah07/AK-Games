# AK’Games — Enrichissement éditorial V3

Ce pack complète la reconstruction de trois bases :

- `data/alerte-rouge.json`
- `data/faux-expert.json`
- `data/faux-expert-adulte.json`

Principes appliqués :

- aucun sujet dupliqué sous une autre formulation ;
- trois choix et trois conséquences propres à chaque scénario d’Alerte Rouge ;
- trois faits spécifiques pour chaque sujet de Faux Expert ;
- aides de bluff adaptées au thème et au sujet ;
- formats et identifiants compatibles avec l’application.

Le ZIP contient uniquement les fichiers à remplacer et les documents de contrôle.
