AK'Games V1.0 — Audit passe 7 : charge et concurrence

Fichiers à remplacer à la racine du projet :
- firebase.js
- database.rules.json
- service-worker.js

Installation :
1. Remplace les trois fichiers dans ton Codespace.
2. Clique sur « Valider et envoyer (push) ».
3. Attends la coche verte dans GitHub Actions.
4. Ferme complètement AK'Games sur les téléphones, puis rouvre l'application.

Important :
La coche verte GitHub confirme aussi que Firebase a accepté les nouvelles règles de base de données.
