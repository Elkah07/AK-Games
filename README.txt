AK'Games V1.0 — Audit passe 10 : chemins morts et cas tordus

Fichiers à remplacer à la racine :
- app.js
- multiplayer.js
- firebase.js
- service-worker.js

Installation :
1. Remplace les quatre fichiers dans ton Codespace.
2. Clique sur « Valider et envoyer (push) ».
3. Attends la coche verte dans GitHub Actions.
4. Ferme complètement AK'Games sur les téléphones, puis rouvre l'application.

Cette passe ne modifie ni les fichiers du dossier data, ni les règles Firebase.
