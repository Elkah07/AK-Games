AK'Games V1.0 — Audit passe 11 : soirée longue

Fichiers à remplacer à la racine :
- app.js
- multiplayer.js
- service-worker.js

Installation :
1. Remplace ces trois fichiers dans ton Codespace.
2. Clique sur « Valider et envoyer (push) ».
3. Attends la coche verte dans GitHub Actions.
4. Ferme complètement AK'Games sur les téléphones, puis rouvre l'application.

Cette passe ne modifie ni les règles Firebase ni les fichiers du dossier data.
